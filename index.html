Key questions

Before you start.

Does BCR32 Studio risk corrupting my hardware presets?+

This is alpha software, not a risk-free guarantee. Sequencer live edits require an explicit switch and affect the current edit buffer. Persistent saving is separate; back up presets before hardware changes.

Where can I download the official Behringer firmware update?+

The official firmware (such as v1.0.3), Quick Start Guides, and device specifications can be downloaded directly from the official Behringer product page at https://www.behringer.com/en/products/0715-AAW.

What browsers support the Web MIDI connection?+

Web MIDI is supported out of the box in Chromium-based browsers: Google Chrome, Microsoft Edge, Brave, and Opera. Connect your BCR-32 via USB and grant MIDI access when prompted.

Can I use BCR32 Studio without a BCR-32 plugged in?+

Yes. You can edit assignments, configure custom labels, generate printable A4 PDF overlays, export Cubase MIDI Remote scripts, and program polyphonic sequences completely offline in your browser.

How does the Cubase MIDI Remote export work?+

The editor generates a complete .js script describing the physical front panel layout and assigned MIDI messages. Place it in Cubase's MIDI Remote Driver Scripts folder to instantly map controls via Cubase's Mapping Assistant.

Is BCR32 backward compatible with BCR2000?+

This standalone distribution contains the BCR32 editor only. The shared MIDI Studio foundation has separate device modules; that does not make their protocols interchangeable.

Get Started with BCR32 Studio

BCR32 Studio is available both as a direct zero-install Web MIDI application and as a local open-source project.

🌐
1. Instant Web MIDI Access (Recommended)

Open the live build directly in Chrome, Edge, Brave, or Opera. Connect your BCR-32 via USB and accept the browser MIDI prompt.

Open editor ↗
⚡
2. Run Locally via Dev Server

Run the Vite development server on your machine with full offline capabilities:

git clone https://github.com/TheLazyGeekGuy/bcr32-studio.git
cd bcr32-studio
npm install
npm run dev -- --port 5183
Then navigate to http://localhost:5183/editor/ in any Chromium browser.
